LOCAL SETUP

내 PC에 파이썬 직접 설치하기 3단계

  1. 1

    설치 파일 다운로드

    공식 홈페이지에서 본인 OS(Windows/Mac)에 맞는 최신 버전을 받습니다.

    python.org/downloads ↗ 공식 포털 · 파이썬 공식 사이트 방문

  2. 2 ★ 가장 중요

    PATH 추가 반드시 체크

    설치 창 하단의 경로(PATH) 추가 옵션을 체크하지 않으면 명령어가 작동하지 않습니다.

    Add python.exe to PATH체크 확인 후 [Install Now] 클릭

  3. 3

    명령 프롬프트(CMD) 검증

    윈도우 검색창에 cmd를 켜고 파이썬 버전 명령어를 입력해 정상 설치를 확인합니다.

    > python --versionPython 3.12.x

직접 겪은 현실적인 고민: 설치까지 마쳤지만, 지금 당장 복잡한 개발 환경이 왜 필요한지 와닿지 않으셨나요?

PROS & CONS

구글 코랩의 강력한 장점과 알아둘 점

강력 추천

코랩을 쓰는 이유 (장점)

  1. 설치 없는 원클릭 환경PC 사양에 상관없이 브라우저만 켜면 즉시 실행
  2. 무료 고성능 GPU 제공비싼 하드웨어 없이도 인공지능/데이터 연산 가속
  3. 구글 드라이브 쉬운 공유구글 문서처럼 링크 하나로 동료와 코드 공유 및 협업

사용 팁

미리 알아둘 점 (주의사항)

  1. 세션 연결 시간 제한일정 미사용 시 자동 세션 종료 및 초기화
  2. 임시 저장 공간의 휘발성세션 종료 시 업로드 파일 삭제 (드라이브 연동 필수)
  3. 인터넷 연결 필수구글 서버 기반이므로 오프라인 환경에서는 작동 불가
한 줄 결론

일부 제한이 있지만, 복잡한 파이썬 설치 과정과 환경 설정 오류를 피할 수 있어 입문 및 실습용으로 가장 이상적인 도구입니다.

CORE INTERFACE

코랩의 핵심 단위: 셀(Cell) 구조

① 코드 셀 · [1] In ② ▶ 실행 버튼 
10 + 20
③ 결과 출력 · Out [1] 30
  1. 1. 코드 셀 (Code Cell)원하는 파이썬 명령을 작성하는 개별 블록입니다.
  2. 2. 재생 버튼 (Run)셀 좌측의 원형 버튼을 누르면 구글 서버에서 연산합니다.
  3. 3. 출력창 (Output)계산된 최종 결과가 셀 바로 아래에 직관적으로 나타납니다.

SHORTCUT POWER

가장 중요한 단축키: Shift + Enter

Shift+Enter

마우스 클릭 대비 10배 빠른 필수 단축키

코드를 작성하고 키보드만 누르면 즉시 실행됩니다.

Shift + Enter를 누르면 현재 셀을 실행한 뒤 자동으로 다음 셀을 생성해 연속 코딩이 가능합니다.

Ctrl + Enter는 현재 셀에 머무르며 결과를 반복 확인할 때 사용
