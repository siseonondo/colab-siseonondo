    로컬

    내 PC에서 실행 (예: 윈도우 파워셀)

    • 실행 창윈도우 파워셀(터미널)에 명령을 입력
    • 준비파이썬 설치, PATH 설정, 패키지 설치
    • 성능내 PC 사양에 따라 달라요
    • 저장내 PC에 그대로 남아요
    • 공유파일을 보내야 해요
    • 인터넷없어도 실행할 수 있어요
    • 환경 오류버전·경로 문제가 생기기 쉬워요

    웹 · 코랩

    구글 서버에서 실행

    • 실행 창브라우저의 코드 셀에 입력
    • 준비브라우저만 열면 바로 시작
    • 성능구글 서버 사용, 무료 GPU도 가능 (한도 있음)
    • 저장세션이 끝나면 사라져요 (드라이브에 따로 저장)
    • 공유링크 하나로 공유
    • 인터넷반드시 필요해요
    • 환경 오류구글이 환경을 맞춰 뒀어요
    한 줄 정리

    ABOUT COLAB

    구글 코랩이란?

    WHAT

    설치 없이 쓰는 파이썬 노트북

    브라우저에서 코드를 쓰고 바로 실행하는 구글의 무료 서비스입니다. 구글 계정만 있으면 됩니다.

    HISTORY

    구글이 만들었고, 2017년경 공개

    원래 연구·교육용으로 쓰던 도구가 누구나 쓸 수 있게 열리면서 데이터 분석과 AI 입문의 표준 도구가 되었습니다.

    WHO

    누가 쓸까요?

    데이터 분석가, AI 연구자, 학생, 그리고 반복 업무를 자동화하려는 일반 직장인까지 폭넓게 씁니다.

    구글 문서와 비교하면

    구글 문서가 글을 쓰고 공유하는 곳이라면, 코랩은 코드를 쓰고 실행하고 공유하는 곳입니다. 링크 하나로 함께 볼 수 있다는 점도 닮았어요.

    CORE INTERFACE

    코랩의 핵심 단위: 셀(Cell) 구조

    + 코드1 + 텍스트4 ▷ 모두 실행5
    ▶2 
    10 + 201
    303
    4내 첫 노트설명 글을 쓰는 칸
    1. 1. 코드 셀 (Code Cell)원하는 파이썬 명령을 작성하는 개별 블록입니다.
    2. 2. 재생 버튼 (Run)셀 좌측의 원형 버튼을 누르면 구글 서버에서 연산합니다.
    3. 3. 출력창 (Output)계산된 최종 결과가 셀 바로 아래에 직관적으로 나타납니다.
    4. 4. 텍스트 셀 (Text Cell)코드가 아니라 설명 글을 쓰는 칸입니다. 실행할 필요 없이 제목과 메모를 적어요.
    5. 5. 모두 실행 (Run all)노트북의 모든 코드 셀을 위에서부터 차례로 한꺼번에 실행합니다.

    중괄호

    문자열 속 빈칸 자리, 또는 이름표 붙인 바구니.

    프롬프트 = "{글}을 요약해줘"

    {글} · 딕셔너리

    한 줄 정리

    ( )는 실행, [ ]는 목록과 번호, { }는 빈칸 또는 이름표 바구니.

    HANDS-ON 02

    실습 2: 여러 개를 한 번에 담는 리스트

    코랩 실제 입력창 [1]

    기본 리스트 문법

    • 대괄호 [ ]는 값을 담는 바구니여러 개의 값을 쉼표(,)로 구분해 한꺼번에 담을 수 있습니다.
    • 번호는 0부터 시작해요첫 번째 값은 과일[0], 두 번째 값은 과일[1]처럼 번호로 꺼냅니다.

    HANDS-ON 03

    실습 3: 하나씩 꺼내 반복하는 for 반복문

    코랩 실제 입력창 [1] 
    과일 = ["사과", "바나나", "포도"]
for 이름 in 과일:
    print(이름, "맛있어요!")
    실행 결과 (Output)사과 맛있어요!
    바나나 맛있어요!
    포도 맛있어요!
